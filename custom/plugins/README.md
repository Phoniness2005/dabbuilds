# Custom plugins

Each custom plugin gets its own subdirectory:

```text
plugins/
  my-feature/
    my-feature.php
    readme.txt
```

Install on Elementor Cloud via ZIP upload or SFTP into `wp-content/plugins/`.

## dabbuilds-hardening

Security headers, REST user lockdown, XML-RPC off, and related hardening for [dabbuilds.com](https://dabbuilds.com). See [`docs/security.md`](../../docs/security.md).
